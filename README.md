# PyTest

个人 Python 试验与练习合集（非单元测试框架）。

## 内容概览

- `game/` / `Pygame/` / `gameobjects/`：Pygame 小游戏与素材
- `Proxy/`、`net/`、`udp/`、`url/`：网络相关试验
- `kafka-test/`、`rabbitMQ/`、`db/`：中间件与数据库试验
- `win32/`、`wxPython/`、`Tool/`、`algorithm/`：Win32 / GUI / 工具与算法草稿

## 运行

需要 Python 3。进入对应子目录按脚本依赖安装（如 `pygame`）后直接运行，例如：

```bash
python fft.py
```

各子目录用途不同，无统一入口。
